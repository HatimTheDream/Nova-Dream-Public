# Nova Dream App Icons

The accepted Red and Cream executive lynx illustrations use the opaque square sources `nova-dream-red-source-v4.png` and `nova-dream-cream-source-v4.png`. The authored files are 1254 × 1254 px, distinct from platform export sizes. Their backgrounds reach every edge, with no black perimeter frame, decorative outline or baked rounded corners. Both retain the selected executive identity: prominent face, gold eyes, black eyebrows, charcoal suit and red tie. The built-in ImageGen refinement removes the earlier border. The generated palette is retained; the interface's exact brand-red token remains `#D93643`.

Regenerate committed platform exports with `node scripts/web-icons.mjs` from the application root. The script pins source hashes and resizes without redrawing. Source artwork, 1024 × 1024 px platform masters, 192 px in-app marks and 180 px Apple touch icons stay opaque. In-app CSS supplies a 24% rounded-corner fallback, upgraded to `corner-shape: squircle` with a 50% radius where supported. Desktop PNG/ICO and ordinary web-app launcher exports use transparent corners matching that squircle: a fourth-power superellipse with antialiased edges. Windows displays these exported edges directly. Do not reintroduce black framing or shrink the face into extra padding. Apple touch icons remain unmasked for system rounding; other platform crops require their own review.

The rail brand and module buttons use **60 × 60 CSS px** at every viewport. This is a display-size choice, separate from bitmap resolution. Apple's archived [QA1686](https://developer.apple.com/library/archive/qa/qa1686/_index.html) gives the standard 60-point iPhone Home Screen icon as 120 × 120 px at 2× and 180 × 180 px at 3×. Modern Apple [App Icons guidance](https://developer.apple.com/design/human-interface-guidelines/app-icons) uses 1024 × 1024 px square layouts with system-applied masking. Nova retains larger source artwork and dedicated web exports; this update does not constitute a tested native iPhone installation.

The two manifests share the same app identity. The saved Appearance choice selects the logo, favicon, touch icon and installation manifest. Existing installed shortcuts can retain their old icon; an in-app selection is not a promise of immediate operating-system icon replacement. Desktop packaging uses Red by default.

The Assistant welcome and every inline or floating voice panel share `NovaAssistantMark`. Red and Cream follow the same saved Appearance choice. The resting expression reuses `/icons/nova-dream-{red|cream}-brand-192-v4.png`; listening and speaking use `/icons/nova-assistant-{red|cream}-{listening|speaking}-256-v1.webp`. The mark uses the app icon's CSS corner shape, with a 44 px voice tile and a 92 px welcome tile reduced to 76 px in narrow layouts. Keep the artwork square and free of surrounding ornaments.

Voice expressions describe current audio activity: connected, unmuted microphone activity selects listening; actual Assistant playback selects speaking. Muting the microphone does not stop playback, so speaking may still appear during a muted call. Connecting, preparing, ending, ended and error states use the resting expression; silence and processing do as well. Changes between voice expressions affect only the Assistant illustration, never the saved App Icon choice, favicon, installation manifest or operating-system icon. Personalized agent portraits, saved appearances and their rendering engines remain unchanged.

`apps/client/public/icons/provenance.json` records source and export hashes. `apps/desktop/lynx-mark.provenance.json` records the default desktop PNG and Windows ICO sizes. Earlier outlined source artwork is historical and must not be selected by current manifests or the application.
