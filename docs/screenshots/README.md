# Screenshot provenance

These images show the actual Nova Dream 1.1.3 browser interface. They were captured from a separate local workspace populated only with fictional tasks, a creative project, sample writing and four demo agents. No maintainer account, message, credential, production workspace or live agent execution is shown.

The five screenshots are unaltered browser captures at the browser's default 1280 × 720 viewport. The Home widgets and hub fit control were adjusted using the application's own controls. The character creator and writing editor were scrolled to their relevant controls. No generated UI mockups or fabricated online activity were used.

- `home.jpg`: Home with Your day and Next work widgets.
- `agent-hub.jpg`: four offices, commons and the central boardroom.
- `character-creator.jpg`: modular wardrobe and directional preview.
- `tasks.jpg`: Today task list.
- `content-writing.jpg`: Markdown editing and formatted preview.

Only these images and documentation are distributed. The screenshot workspace and its local encryption key are excluded from Git.
