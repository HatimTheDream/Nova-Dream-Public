# Screenshot provenance

These are actual Nova Dream **1.5.10 / build 1.0.167** browser screenshots, captured on 16 September 2026 from the same verified application candidate as the current release.

The isolated local workspace contains only fictional tasks, a creative project, sample writing and four demo agents. No owner account, private message, credential, production data or live AI activity is shown. Agents correctly appear offline when their state is visible. The demo database and encryption key are excluded from Git.

All six images are unaltered browser captures at the default **1280 × 720** viewport. Home widgets were hidden using their normal options to frame the cover image. The hub uses Fit all rooms; the character and writing editors were scrolled using normal controls. No generated mockups or fabricated online activity were used.

- `home.jpg`: customizable Home with the accepted red-outline logo and a fictional task plan.
- `agent-hub.jpg`: four individual offices, commons and the central boardroom.
- `character-creator.jpg`: modular wardrobe, expressions, motion and eight-direction preview.
- `tasks.jpg`: current Today task list.
- `content-writing.jpg`: Markdown writing and formatted preview.
- `settings.jpg`: compact Settings categories, including Usage and Devices.

The gallery is shared with the public source repository. Screenshots document the stated version; the application changelog and GitHub Releases describe subsequent updates.
